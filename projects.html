AroggyaGram-3
Intelligent Community Health Network

Active Production Deployed

" When an emergency strikes in an isolated area, the bottleneck is rarely a total lack of resources — it is the total lack of an intelligent coordination layer to route human help within minutes.

Context

Critical healthcare delivery in decentralized communities suffers from severe information fragmentation. Emergency calls are often frantic, unstructured, and fail to reach nearby field responders who have the right medical supplies.

System Architecture

Engineered an end-to-end multi-agent dispatch network. Ingests raw audio/text distress signals, processes intent via LLM agents, tags triage severity levels, and maps tasks to verified community workers using geo-fenced proximity scoring.

Implementation

Full-stack TypeScript architecture built with Next.js, reactive state pipelines, low-latency WebSocket dispatch, and Gemini API integration for adaptive multilingual emergency triage.

Engineering Decisions

Prioritized zero-dependency fallback: offline SMS-burst capability when cell data is degraded, and deterministic failover routing so no distress signal remains unacknowledged.

TypeScript Next.js AI Agents Geocoding Distributed Health
Outcome
Active

Working full-stack deployment turning human crisis into synchronized real-world field logistics. Validated through end-to-end multi-user emergency simulations.

Reflection

Proves that generative AI belongs at the translation boundary—turning chaotic, terrified human speech into strict, structured JSON payloads that existing logistics software can act upon.

F1 Monte Carlo
Race Strategy Simulator

Live System Live Demo

" Grand Prix race strategies aren't won on fixed spreadsheets — they are won by evaluating tens of thousands of stochastic futures before the first pit window opens.

Context

Formula 1 race engineering involves navigating extreme non-linearities: tyre compound thermal degradation, safety car probabilities, fuel-mass delta lap time penalties, and rival undercut dynamics under variable track conditions.

Vectorized Engine

Engineered a vectorized Monte Carlo engine in Python leveraging NumPy arrays to execute 10,000 complete race trajectories in milliseconds. Incorporates non-linear wear profiles calibrated with FastF1 telemetry feeds.

Decision Optimization

Coupled stochastic simulation with a dynamic programming solver based on the Bellman equation to find the globally optimal pit strategy (lap count, compound choice, safety car response) under uncertain weather states.

Stack & Performance

Python backend leveraging vectorized linear algebra, FastAPI compute endpoints, and a high-framerate interactive React front-end delivering live probability curves and telemetry graphs.

Python NumPy FastF1 API Dynamic Programming React Monte Carlo
Outcome
10k+

Vectorized simulations per compute pass. Deployed and live for interactive user experimentation with real historical Grand Prix telemetry datasets.

Reflection

Showcases how high-performance numerical computing and clean web visual interfaces transform raw mathematical uncertainty into clear tactical decisions.

AutoMeter
Smart Fare Meter & Dynamic UPI

Tested & Operational Hardware-Software

" For decades, informal auto-rickshaw fleets in India have struggled with rigged meters, currency friction, and payment disputes. AutoMeter replaces mistrust with automated verification.

Context

Millions of urban daily commutes rely on auto-rickshaws. Analog mechanical meters are easily manipulated, lack real-time digital payment reconciliation, and force passengers and drivers into awkward disputes over change.

Sensor Fusion Logic

Engineered a dual-input tracking system combining high-frequency GPS position deltas with physical wheel rotation pulses to calculate accurate distance even through tunnels and dense urban canyons without spoofing vulnerabilities.

Dynamic UPI Integration

Upon ride termination, the system generates a dynamic on-screen Unified Payments Interface (UPI) QR code embedded with the exact calculated amount, ride transaction hash, and merchant VPA for instant zero-fee passenger checkout.

Build Decisions

Built with Flutter and Android Native services. Designed with a sunlight-readable, high-contrast UI tailored specifically to harsh vibration, high-glare automotive environments.

Flutter Android Native Sensor Fusion UPI Protocol IoT Transit
Outcome
0 Friction

Operational smart meter prototype supporting instant dynamic QR scan-and-pay, automated fare brackets, and transparent driver analytics.

Reflection

Built upon my earlier 1st-place award-winning research in transit tracking, demonstrating how software can modernize essential public mobility without imposing expensive corporate hardware.

Opportunity
Offline-First Task & Life OS

Production Ready Android Native

" Most productivity tools fail because they assume unlimited human cognitive energy. Opportunity plans around your real daily energy budget and stays 100% functional without the cloud.

Context

Cloud-dependent task managers suffer from network lag, subscription lock-in, and unrealistic planning that leads to user burnout. Opportunity was designed as an offline-first deterministic executive system.

Scoring & Capacity Engine

Features an algorithm that weights task difficulty, urgency, and calendar context against a capacity-aware daily budget—preventing over-scheduling and re-prioritizing remaining tasks dynamically when schedules slip.

Modern Android Stack

Crafted in pure Kotlin using Jetpack Compose, Material 3 theming, Room SQLite Database for offline persistence, WorkManager for reliable background alarms, and an accompanying Wear OS companion tile.

Architecture

Strict Unidirectional Data Flow (UDF) with Coroutines and StateFlow. Fully decoupled data access layers guaranteeing zero UI thread stutters and 60 FPS transitions.

Kotlin Jetpack Compose Room DB Wear OS WorkManager UDF Architecture
Outcome
100%

Zero cloud dependency. Complete local privacy, instant sub-millisecond query responses, and resilient cross-device synchronization to Wear OS watches.

Reflection

Highlights the beauty of Native Android engineering when unburdened by bloated external SDKs—delivering clean, battery-efficient tools built for human focus.

CRT Modular Lock
& 3D Interactive Web Mechanics

Interactive Live Live Demo

" The Chinese Remainder Theorem is usually taught through dry modular arithmetic equations. Building it as an interactive, tactile digital tumbler lock transforms an ancient theorem into intuition.

Context

Explores the border where mathematical theorems, physical mechanical puzzles, and high-framerate front-end engineering merge. Digital recreation of a physical cardboard CRT lock mechanism.

Mechanical Interaction

Users rotate three modular dial rings ($m_1=3, m_2=5, m_3=7$), spin the central number wheel, and pull the sliding rod to align notched gates, release the spring latch, and swing open the safe door.

Creative Stack

Engineered with React, TypeScript, Tailwind CSS, and Framer Motion spring physics. Accompanied by WebGL experiments in Three.js and Canvas frame-sequence animations (The Ford GT, 3D WebGL fruits, AR jewelry engines).

Design Standards

Pixel-perfect haptic feedback simulation, audio-visual feedback on alignment notches, and responsive touch gestures across desktop trackpads and mobile screens.

React TypeScript Framer Motion Three.js WebGL Number Theory
Outcome
60 FPS

Fluid spring-physics animation running live in production. Deployed interactive web demo with open-source component architecture.

Reflection

Proves that the web can feel physical, mechanical, and delightful when animations obey real inertia and physical resistance laws.
